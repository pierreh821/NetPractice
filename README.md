# NetPractice

## Description
NetPractice is an introduction to the basics of computer networking. It requires to learn how to configure IP adresses, connect devices
through a router, and understand the role of a gateway within a network.

## Instructions
To open the project's interface in browser, run in the path_to_project/interface:

```sh
./run.sh
``` 

On the interface, you will have to complete 10 levels of exercises. The "Get my config" button exports your current configuration into a json file.

## Resources

The studied concepts in NetPractice are:
- TCP/IP adresses
- adressing
- router
- switches
- default gateway
- subnet masks
